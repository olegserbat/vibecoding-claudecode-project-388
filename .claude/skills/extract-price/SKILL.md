# extract-price

Извлечение цены товара с одной страницы по URL. Результат — строго один
JSON-объект, без пояснений вокруг него.

## Когда использовать

- «Какая цена вот тут: <URL>»
- «Достань цену и скидку со страницы товара»
- «Есть ли на этой странице рассрочка/кредит?»
- «Спарси цены по этим ссылкам» (обрабатывать каждый URL отдельно)

## Вход

Один URL страницы товара. Если URL не дан — спросить его, не угадывать.

## Выход

Ровно один JSON-объект:

```json
{
  "regular_price": 1299.00,
  "sale_price": 999.00,
  "has_credit": true
}
```

- `regular_price` — обычная (полная, «старая») цена, число или `null`.
- `sale_price` — цена по скидке, число или `null`, если скидки нет.
- `has_credit` — `true`/`false`: доступна ли рассрочка или кредит.

Цены — JSON-числа с двумя знаками после десятичной точки: рубли до
точки, копейки после. Не строки: ни пробелов-разделителей разрядов, ни
запятой, ни кавычек, ни символа валюты.

Никаких дополнительных полей. Если цену найти не удалось — `null`,
никогда не выдумывать и не оценивать «примерно».

## Алгоритм

### 1. Загрузить HTML

Использовать `WebFetch` для URL; если нужен сырой HTML — `curl -sL` с
обычным User-Agent браузера. Следовать редиректам.

Если страница отдала ошибку, требует капчу/авторизацию или цена
подгружается только JavaScript'ом и в HTML её нет — вернуть
`{"regular_price": null, "sale_price": null, "has_credit": false}` и
одной строкой сказать причину. Не обходить защиту сайта и не подбирать
обходные пути к закрытому контенту.

### 2. Найти цены — по приоритету источников

Идти сверху вниз, останавливаться на первом источнике, где цена есть:

1. **JSON-LD** — `<script type="application/ld+json">`, объекты
   `Product` / `Offer` / `AggregateOffer`: поля `price`, `lowPrice`,
   `highPrice`, `priceSpecification.price`.
2. **Microdata / RDFa** — `itemprop="price"`, `itemprop="lowPrice"`
   (значение брать из `content`, если атрибут есть).
3. **Мета-теги** — `product:price:amount`, `og:price:amount`,
   `twitter:data1`.
4. **Разметка страницы** — элементы с классами/атрибутами, содержащими
   `price`, `cost`, `amount`, `цена`; атрибуты вида `data-price`.

### 3. Различить обычную цену и цену по скидке

- Найдена **одна** цена → она `regular_price`, `sale_price` = `null`.
- Найдены **две и более** → полная цена та, что зачёркнута или помечена
  как старая: теги `<del>`, `<s>`, `<strike>`, классы со словами `old`,
  `was`, `crossed`, `strike`, `regular`, `base`, `старая`;
  либо `listPrice` / `highPrice` в структурированных данных.
  Актуальная (обычно меньшая, выделенная) → `sale_price`.
- Явных маркеров нет, но цен две → большая в `regular_price`, меньшая в
  `sale_price`.
- Диапазон цен («от 1 000 до 2 000») → брать нижнюю границу как
  `regular_price`, `sale_price` = `null`.
- Цены разных вариантов товара (размер, цвет) → брать цену варианта,
  выбранного на странице по умолчанию.
- Не путать с ценой других товаров: игнорировать блоки «похожие»,
  «рекомендуем», «с этим покупают», «вы смотрели».
- Не принимать за цену: цену доставки, сумму корзины, размер скидки
  в рублях, кешбэк, бонусы, стоимость услуг и гарантии.

### 4. Определить has_credit

`true`, если рядом с ценой или в блоке покупки есть признаки рассрочки
или кредита:

- слова «рассрочка», «в рассрочку», «кредит», «в кредит», «беспроцентн»;
- платёж по частям: «₽/мес», «руб./мес», «в месяц», «×4 платежа»,
  «0-0-4», «0-0-12»;
- названия сервисов: Халва, Долями, Podeli, Сплит, Яндекс Сплит.

Иначе `false`. `has_credit` — всегда булево, никогда `null`.
Упоминание кредитных сервисов в подвале сайта или в общей рекламе, не
привязанное к этому товару, не считается.

### 5. Нормализовать значения

Из найденного текста цены:

1. Убрать валюту и всё лишнее: `₽`, `руб`, `руб.`, `RUB`, `р.`, а также
   слова вокруг («цена», «от», «всего»).
2. Убрать все пробелы, включая неразрывный (U+00A0) и тонкий (U+2009).
3. Разделитель дробной части — последняя запятая или точка, за которой
   идут ровно 1–2 цифры; всё остальное считать разделителями разрядов и
   удалять. `1.299,50` → `1299.50`; `1,299.50` → `1299.50`;
   `1 299` → `1299`.
4. Привести к числу и округлить до 2 знаков. Если копеек нет — это
   всё равно число с нулевой дробной частью (`1299` → `1299.00`).
5. Записать в JSON как число с десятичной **точкой** и двумя знаками
   после неё. Никаких кавычек, разделителей разрядов, запятых и символа
   валюты в значении.

Примеры:

| В HTML | Результат |
|---|---|
| `1 299 ₽` | `1299.00` |
| `1299` | `1299.00` |
| `1 299,5 руб.` | `1299.50` |
| `1.299,00 ₽` | `1299.00` |
| `129 990 ₽` | `129990.00` |
| цены нет | `null` |

Валюту в результат не включать: подразумеваются рубли. Если цена на
странице явно в другой валюте — не конвертировать, вернуть `null` и
сказать об этом одной строкой.

## Чего не делать

- Не выдумывать и не «прикидывать» цену, если её нет в HTML — только `null`.
- Не обходить несколько страниц: скил работает ровно с одним URL за раз.
- Не добавлять в JSON лишние поля и не оборачивать ответ в пояснения.
