# Skills

Эта папка — хранилище скилов (skills) для Claude Code в этом репозитории.
Скил — это переиспользуемый набор инструкций для конкретной повторяющейся
задачи (ревью по чек-листу, деплой, генерация отчётов и т.д.), который
Claude подгружает по названию через `/<имя-скила>` или автоматически по
описанию.

## Структура

Каждый скил — это отдельная директория внутри `.claude/skills/` с файлом
`SKILL.md` внутри:

```
.claude/skills/
  README.md          <- этот файл
  _template/          <- заготовка, копируйте её для нового скила
    SKILL.md
  my-skill/
    SKILL.md
    references/       <- (опционально) дополнительные материалы, примеры
```

Имя директории = имя скила, которое используется в `/имя-скила`.

## Как добавить новый скил

1. Скопируйте `_template` в новую директорию с именем скила
   (только строчные буквы, цифры и дефисы, например `deploy-check`).
2. Заполните frontmatter и тело `SKILL.md` (см. шаблон).
3. Опишите в `description`, когда именно скил должен срабатывать —
   это единственное, что видит Claude при выборе скила автоматически.
4. Проверьте скил в деле и при необходимости используйте `skill-creator`
   для доработки и прогона эвалов.

## Соглашения

- `description` пишется от третьего лица и явно перечисляет триггеры
  (ключевые слова, ситуации), а не только общее назначение скила.
- Не дублируйте в `SKILL.md` то, что Claude и так знает — только
  специфику этого проекта/процесса.
- Если скилу нужны вспомогательные файлы (шаблоны, схемы, скрипты),
  кладите их рядом в поддиректорию, а не в тело `SKILL.md`.
